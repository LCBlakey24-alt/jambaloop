# Question fact-check, 27 November 2026

Every question in the library was reviewed on this date: 2,696 rows across all
topics and formats, the So Close measurement bank and the Rare Find answer sets.

**How it was done.** Eight automated reviewers each read one batch row by row.
They used web searches for news, sports statistics and anything they were not
sure of (roughly 110 rows in total); everything else was checked from general
knowledge, not against a cited source. This is an editorial review. It does not
make any question "source-verified".

**Result.** 86 rows flagged. None had a wrong marked answer.

| Kind | Count | What was done |
|---|---|---|
| A "wrong" option was arguably right, or the fact is contested | 21 | Option swapped or prompt reworded |
| Wording slip or misleading premise | 17 | Reworded |
| True today but will go out of date | 48 | Reworded to a dated or past-tense form where that made it permanent; the rest are listed below |

59 rows were edited, two duplicates were replaced, and the Rare Find polygon
set now accepts Square, Rectangle and other four-sided shapes.
